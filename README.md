# 🚀 CREATE ZOOM ACCOUNT AUTOMATION - JUY PROJECT

Bot otomatisasi pendaftaran akun Zoom menggunakan Node.js dan Puppeteer. Dilengkapi dengan sistem keamanan lisensi, panel admin, dan fitur anti-stuck.

## 🛠️ Fitur Utama
* **Auto Registration**: Membuat akun Zoom secara otomatis.
* **PIN Stabilizer**: Mengisi kode verifikasi PIN Zoom secara akurat.
* **Anti Error 33000**: Otomatis mengganti email jika terkena blokir sistem Zoom.
* **Private Admin Panel**: Mengelola lisensi dan melihat database akun yang berhasil dibuat.
* **License System**: Keamanan akses bot melalui @juy_market.

---

## 📥 Instalasi

Ikuti langkah-langkah di bawah ini untuk menjalankan bot di komputer Anda:

### 1. Install Node.js
Pastikan Anda sudah menginstal **Node.js** (Versi LTS direkomendasikan).
Jika belum punya, unduh di: [nodejs.org](https://nodejs.org/)

### 2. Persiapan Folder
Download atau clone repository ini, lalu masuk ke folder project:
```bash
cd folder-juy-project


3. Install Dependencies
Buka Terminal/CMD di folder tersebut dan jalankan perintah:
Bash
npm install

## 🚀 Cara Menjalankan
Pastikan Anda berada di folder project, lalu jalankan perintah:
bash
npm start

🎮 Kontrol Saat Berjalan
Masukkan Kode Akses: Gunakan kode dari admin.

Berhenti (Stop): Tekan tombol 'S' pada keyboard saat bot berjalan untuk berhenti secara aman dan kembali ke menu.

Menu Admin: Masukkan Master Key untuk mengakses database dan mengubah lisensi.



⚠️ Troubleshooting
Error Cannot find module 'puppeteer': Jalankan kembali npm install.

Kode Akses Salah: Silahkan hubungi Telegram @juy_market untuk mendapatkan akses terbaru.

Stuck di OTP: Bot akan mencoba me-refresh otomatis sebanyak 4 kali sebelum mengulang sesi.
